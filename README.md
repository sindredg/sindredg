Hi, I'm Sindre. I like figuring out how cloud infrastructure and identity systems fit together,
usually with Terraform, a few diagrams and more notes than I expected to write.

I work across Azure, Google Cloud and AWS. This profile is where I keep labs, experiments and
small projects from things I wanted to understand a little better.

## What I've been tinkering with

- **Identity across clouds** — [Entra ID to AWS IAM Identity Center](https://github.com/sindredg/cross-cloud-entra-aws) and a [two-site AD DS lab synced to Entra ID](https://github.com/sindredg/two-site-hybrid-identity)
- **Identity and access** — [Conditional Access, PIM and access reviews](https://github.com/sindredg/Access-Control-and-Identity-Governance), plus [OIDC SSO and SCIM for Grafana](https://github.com/sindredg/entra-app-roles-sso-scim)
- **Cloud platforms** — an [Azure Container Apps setup](https://github.com/sindredg/container-app-in-azure), a [GKE/Kubernetes lab](https://github.com/sindredg/k8-lab) and a [hub-and-spoke Azure network](https://github.com/sindredg/hybrid-network-az)
- **Apps and authentication** — [Sky](https://github.com/sindredg/sky), an [OAuth and token claims demo in .NET](https://github.com/sindredg/app-registrations-and-JWT-tokens) and some [least-privilege Azure MCP work](https://github.com/sindredg/claude-azure-mcp-rbac-design)

Feel free to look around. Most repositories include the notes, decisions and occasional wrong turn
that went into them.
